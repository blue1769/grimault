# [도메인] 기능명

## 개요

해당 기능의 목적과 적용되는 비즈니스 규칙을 간략하게 설명한다.

## 테스트 대상

- `[ServiceClass].[method]`

## 테스트 시나리오

### 1. [검증할 비즈니스 규칙과 기대 결과]

- **대상:** `[ServiceClass].[method]`
- **시나리오:** 어떤 조건에서 어떤 비즈니스 규칙을 검증하는가
- **사전 조건:** 필요한 입력 데이터 및 기존 상태
- **실행:** 검증할 동작
- **기대 결과:** 예상 반환값, 상태 변경, 예외 또는 호출 결과
- **테스트 형태:** `@Test`

### 2. [동일 규칙에 대해 여러 입력을 검증하는 경우]

- **대상:** `[ServiceClass].[method]`
- **시나리오:** 여러 입력에 공통으로 적용되는 비즈니스 규칙
- **사전 조건:** 검증에 필요한 상태 및 입력 데이터
- **실행:** 검증할 동작
- **기대 결과:** 각 입력에 대해 충족해야 하는 결과
- **테스트 형태:** `@ParameterizedTest`

#### 입력 조건

| 입력 | 기대 결과 |
|---|---|
| [입력 A] | [결과 A] |
| [입력 B] | [결과 B] |
